# Orange AI Desktop

Official release and distribution repository for **Orange AI Desktop**.

## Releases & Downloads

To download the latest verified release of Orange AI Desktop for Windows:
- Visit [Releases](https://github.com/blAkeHoax/orange-ai/releases) to download the standalone installer (`Orange AI_<version>_x64-setup.exe`).
- Automated updates are published with cryptographic Minisign signatures and update manifests (`latest.json`).

## Security & Verification

All official updates and recovery installers are built and signed from the private build pipeline.
